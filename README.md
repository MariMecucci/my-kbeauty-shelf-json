# My K-Beauty Shelf — JSON

> My favorite k-beauty products

A small data project that turns some of my favorite K-Beauty products into semi-structured JSON data and uses Python to read, filter and summarize the collection.

The dataset includes products from brands such as Medicube, Biodance, Lilyeve, COSRX, Sulwhasoo, IOPE, Abib, DR.REJUALL and CKD.

## Data Flow

K-Beauty Products  
→ Structured JSON  
→ Python  
→ Filtering  
→ Aggregation  
→ Beauty Insights
